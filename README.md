# Algoritmos e Programação Orientada a Objetos

Atividades e trabalhos em **Java** dos primeiros semestres de Engenharia de Software na
UNIPAMPA (2024). É o registro da base de programação do curso: lógica, orientação a
objetos, interfaces gráficas com Swing e documentação com Javadoc.

## Conteúdo

| Pasta | O que tem |
| --- | --- |
| [`2024.01/`](2024.01/) | Trabalhos de Algoritmos e Programação: `TrabalhoI`, `TrabalhoII`, um jogo de mesa com jogadores (`Trabalho2`) e leitura de arquivo |
| [`Atividades/`](Atividades/) | Exercícios de orientação a objetos (ex.: `Carro` e `Estacionamento`) |
| [`PREA/`](PREA/), [`T2POO/`](T2POO/) | Jogo de tabuleiro *Preá × Estudantes* com interface Swing, feito em dupla para POO |
| [`WindowBuilder/`](WindowBuilder/), [`interfaces/`](interfaces/) | Interfaces gráficas em Swing (inclui um "botão fujão" e componentes customizados) |
| [`trabalhoI_POO/`](trabalhoI_POO/) | Documentação Javadoc gerada do Trabalho I de POO (`Produto`, `Empacotador`) |
| [`CoodingDojo2/`](CoodingDojo2/), [`CoodngDojoII/`](CoodngDojoII/) | Exercícios feitos em sessões de Coding Dojo |
| [`GuriasOfCode/`](GuriasOfCode/) | Página web (HTML + Bootstrap) do projeto Gurias of Code, com personas |

## Como rodar

Os projetos são Java puro, sem dependências externas. Os que têm pasta `.idea/` abrem direto no IntelliJ;
os demais compilam com `javac` a partir da pasta do exercício.

> Trabalhos iniciais da graduação, mantidos como registro da evolução. Os projetos mais
> recentes estão fixados no [meu perfil](https://github.com/lilydias24).
